# MCAD

(Minecraft Computer Aided Design)

## Setup

Download latest release along with current [Fabric API (fabric-api-0.162.0+26.3.jar)](https://www.curseforge.com/minecraft/mc-mods/fabric-api/files/9557683)

Brief guide on MCAD available at [baburke.com/mcad](https://baburke.com/mcad)
